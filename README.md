# Gaming Control Panel

Modern gaming dashboard featuring player management, progression systems, licenses, businesses, properties, and battle pass administration.

## Features

- Player Profiles
- Progression System
- Licenses Management
- Business Management
- Properties Management
- Battle Pass System
- Responsive Dashboard UI

## Tech Stack

- React
- TypeScript
- Tailwind CSS
- Vite
